# Three-minute product walkthrough

Before recording: connect Hindsight, confirm authentication, select live reasoning, and use a new guided example. Keep synthetic-data labels visible. Never claim a local run is Hindsight-powered.

## 0:00–0:25 The problem

Show Strategy brief. Say: “Our product team sees competitor job postings, messaging changes, and releases. Each looks ordinary on its own. STRATAMEM helps us connect them, record an explanation, and learn whether it was right.”

## 0:25–0:55 One signal

Open Guided demo and save the first hiring event. Run the first assessment. Show that the answer has limited evidence. In a live recording let the call finish; do not mask a failure as success.

## 0:55–1:30 History changes the interpretation

Add the remaining history. Analyze again with Hindsight selected. Show the returned assessment. Open Memory & activity to show actual Retain, Recall, and Reflect records and the retrieved text. Explain that the three observed events are facts within the fictional scenario; expansion is still a hypothesis.

## 1:30–2:10 Make it testable

Return to the guide and save the suggested enterprise-expansion hypothesis. Review the expected signal and attached events. Choose a later pricing launch or cancellation. Review and save the outcome and lesson.

## 2:10–2:45 Use the lesson

Analyze again. The backend syncs the outcome lesson before Recall/Reflect. Show whether the actual returned answer uses that lesson. A single example does not prove prediction accuracy; it proves the persistence and reasoning workflow.

## 2:45–3:00 Close

Export a brief. Say: “The product remembers not only competitor activity but what we believed and what happened next. We can inspect the evidence and challenge the hypothesis.”

Recording duration depends on live service latency. A 2–5 minute submission video can show the completed requests with clear cuts. Disclose cuts; do not replace them with fabricated responses.
